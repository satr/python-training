# Data engineering

Build reliable transformations with explicit schemas, quality checks,
idempotent writes, and observable pipeline boundaries.

## Exercises

1. [Normalize events](exercise01_normalize_events) - normalize and deduplicate
   untrusted event records.
2. [SQLite warehouse](exercise02_sqlite_warehouse) - load transactional data
   and query daily totals.
3. [Polars lazy aggregations](exercise03_polars_lazy_aggregations) - validate a
   typed frame and execute a lazy grouped query.
4. [Parquet projection](exercise04_parquet_projection) - enforce an Arrow
   schema and read filtered, projected Parquet data.
