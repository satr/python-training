# AI applications

Learn the deterministic building blocks and evaluation methods behind AI
applications before connecting to model providers and vector databases.

## Exercises

1. [Vector search](exercise01_vector_search) - rank embeddings with cosine
   similarity.
2. [Retrieval evaluation](exercise02_retrieval_evaluation) - measure retrieval
   quality across evaluation cases.
3. [NumPy feature scaling](exercise03_numpy_feature_scaling) - fit reusable
   preprocessing parameters without data leakage.
4. [PyTorch binary classifier](exercise04_pytorch_binary_classifier) - train a
   tiny deterministic linear model on CPU.
