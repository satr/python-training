# Core Python

Build practical programs with Python's core syntax, collections, object model,
standard library, and type system before introducing frameworks.

Work through the exercises in order:

1. [Values and strings](exercise01_values_and_strings)
2. [Conditionals and booleans](exercise02_conditionals_and_booleans)
3. [Loops and ranges](exercise03_loops_and_ranges)
4. [Functions and parameters](exercise04_functions_and_parameters)
5. [Lists and tuples](exercise05_lists_and_tuples)
6. [Dictionaries and sets](exercise06_dictionaries_and_sets)
7. [Comprehensions](exercise07_comprehensions)
8. [Classes and dataclasses](exercise08_classes_and_dataclasses)
9. [Exceptions and validation](exercise09_exceptions_and_validation)
10. [Iterators and generators](exercise10_iterators_and_generators)
11. [Files and context managers](exercise11_files_and_context_managers)
12. [Modules and standard library](exercise12_modules_and_standard_library)
13. [Decorators and closures](exercise13_decorators_and_closures)
14. [Typing and protocols](exercise14_typing_and_protocols)
